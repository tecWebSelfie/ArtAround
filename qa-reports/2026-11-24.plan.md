## Ranked flows

### a) Touched since PREV_SHA

1. **Search leaks (live Typesense)** — risk high, never tested live.
   - Preconditions: reseeded DB, a user with a private content, a private
     tour, a visit copy, a paid content with a marker in its body.
   - Steps: `/api/navigator-search`, `/en/search/{tours,contents,objects}`
     (HTML and RSC payload with `RSC: 1`), museum mode cookie, `?author=`,
     `?subject=`, picker mode `?pick=tour&museum=&returnTo=&have=`.
   - Hostile: flip visibility public→private→public quickly and
     concurrently (Promise.all) and check the index for stale rows; delete a
     content and search its title; rename a museum; huge/odd `q`,
     `page=-1`, `page=1e9`, array params, filter syntax (`&&`, backticks,
     `:=`) in every param; another museum's id in museum mode.
   - Expected: no private/personal/empty document listed or hydrated; no
     paid body in any HTML or RSC payload (hydration uses
     `docsInHitOrder` with the Local API default `overrideAccess: true`);
     400/empty for hostile params, never 500 with a stack.
   - Observe: grep responses for markers, Typesense collection contents
     (`curl :8108` with the dev key), server log.
2. **Tour navigation changes** (B) — risk medium.
   - Position prompt, route start, journey framing, walk-to, guest ghost.
   - Hostile: step ids of another tour or museum in the URL, a private
     tour's id, refresh and back/forward mid-route, offline map assets
     (`page.route` abort), GPS simulator off, a tour with no placed
     entrance, a museum without a map.
   - Expected: no crash (error boundary), no private data, a sensible
     fallback position.
3. **Sign-up hook** (`sanitizePublicSignup`) — `POST /api/users` with body
   `null`, `[]`, `"x"`, `{roles:[…], isSuperAdmin:true}` as JSON and as
   multipart `_payload`. Expected 400 and never a privileged field stored.
