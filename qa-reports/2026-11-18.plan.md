## b) Area C attacks

5. **Guest identity takeover**: identities `guest-<X-Guest-Id>` are visible to
   every participant. Guest X reads guest V's identity, then
   `POST /api/rooms/token` with `X-Guest-Id: <V's id>` → gets V's identity:
   V is disconnected (duplicate identity) and X publishes V's `quizToken` /
   `quizDone` / `requests` attributes. Expected: a guest id cannot be claimed
   by another device (e.g. bound to a secret). Observe with livekit-server-sdk
   `RoomServiceClient.listParticipants` or two Playwright browsers.
6. **Room name race / hijack**: concurrent `POST /api/rooms` with the same
   `groupName` (Promise.all ×10): exactly one 200, others 409; the winner's host
   key still works afterwards (metadata not overwritten). Also re-create a name
   right after `DELETE`.
7. **Group cookie after the group ends**: host `DELETE /api/rooms/CODE`; guest
   keeps reading the private tour/contents with the cookie for up to 4 h.
   Document as design question unless it contradicts docs.
8. Host key: `DELETE` and host token with a wrong / empty / other room's key →
   403 / guest token; `X-Host-Key` of room A on room B.
9. Token endpoint inputs: `room_name` lower-case, unicode, 1000 chars,
   `participant_name` empty/huge/HTML, missing/short `X-Guest-Id`, guest id
   `host`-like strings → 400, never 500; identity never equals `host`.
10. Grants: a guest token cannot publish data/tracks, cannot update other
    participants; a guest setting its own `path` or `quiz` attribute is ignored
    by followers (only `host` identity trusted) — check in GroupSync code + browser.
11. Group quiz: `groupQuizScores` with tokens of another tour, 200 tokens,
    duplicates; `submitQuizAttempt` with `choices` for question ids not in
    the quiz, a 100k-entry `choices` record, `stepsCompleted` huge/negative,
    unknown `lng`; duplicate concurrent submits.
12. UI (Playwright, 2–3 browsers): host reload / back-forward mid-modal, guest
    refresh mid-quiz, offline guest (`page.route` abort) then reconnect, host
    disconnect, late joiner after "End quiz", joining an ended room by link.
